# ШагРитм

Мобильное приложение-шагомер на Expo и React Native.

## APK для телефона

Готовый установочный файл Android:

```text
C:\Users\user\repositories\public\шагомер\dist\pedometer-android.apk
```

Скопируйте этот APK на Android-телефон и откройте его на телефоне. При установке Android может попросить разрешить установку из неизвестного источника для приложения, через которое вы открываете APK.

После первого запуска выдайте разрешения:

- Physical activity / Физическая активность - нужно для подсчета шагов.
- Notifications / Уведомления - нужно на Android 13+, чтобы работал постоянный фоновый сервис шагомера.

## Что важно для реального подсчета

На Android приложение использует нативный `TYPE_STEP_COUNTER` датчик и foreground service. Это значит, что счетчик продолжает работать в фоне, пока Android не остановит приложение вручную и пока активен сервис шагомера.

Чтобы счетчик работал стабильнее:

- не закрывайте приложение принудительно из настроек Android;
- не отключайте уведомление шагомера;
- после перезагрузки телефона откройте приложение один раз;
- при необходимости отключите жесткую экономию батареи для приложения.

## Где открыть

- Web-preview интерфейса: http://localhost:8082

Web-preview нужен только для просмотра интерфейса в браузере. В браузере нет датчика шагов, поэтому реальные шаги считаются только в Android APK.

## Запуск

```powershell
npm install
npm start
```

Для просмотра интерфейса в браузере:

```powershell
npm run web
```

## Важно

В проекте есть нативная папка `android/`, потому что для полноценного Android-шагомера добавлен собственный модуль и foreground service. Это не Expo Go-приложение для реального использования, а нативный APK.
