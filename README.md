# ШагРитм

Мобильное приложение-шагомер на Expo и React Native.

## Автообновление приложения на телефонах от компьютера

Для разработки телефоны можно подключить к этому компьютеру как к локальному серверу. В этом режиме приложение на каждом подключенном телефоне берет код с Metro-сервера на компьютере, а изменения в `.ts` и `.tsx` файлах появляются на телефонах автоматически через Fast Refresh.

Первый раз установите debug-сборку на нужный телефон:

```powershell
npm run phone:install
```

После этого подключите один или несколько телефонов по USB и для ежедневной разработки запускайте:

```powershell
npm run phone:live
```

Что должно быть готово на каждом телефоне:

- телефон подключен к компьютеру по USB;
- на телефоне включен Developer mode / Режим разработчика;
- включен USB debugging / Отладка по USB;
- на телефоне подтвержден RSA-запрос от этого компьютера;
- на компьютере доступны Android SDK Platform Tools с `adb.exe`;
- для установки или пересборки debug APK нужны JDK и Android SDK.

Держите окно `npm run phone:live` открытым. Команда сама найдет все подключенные Android-телефоны, подключит каждый к Metro-серверу и откроет приложение. Когда вы меняете файлы интерфейса или логики React Native, все подключенные телефоны обновляют экран автоматически.

Если менялись native-файлы Android, например `android/app/src/main/java/...`, `AndroidManifest.xml`, зависимости или `app.json` permissions, нужен новый APK:

```powershell
npm run phone:rebuild
```

Обычный release APK из `dist/` не подключается к компьютеру как к серверу и не получает локальные изменения автоматически.

## APK для телефона

Готовый установочный файл Android:

```text
C:\Users\user\repositories\public\шагомер\dist\pedometer-android.apk
```

Скопируйте этот APK на Android-телефон и откройте его на телефоне. При установке Android может попросить разрешить установку из неизвестного источника для приложения, через которое вы открываете APK.

После первого запуска выдайте разрешения:

- Physical activity / Физическая активность - нужно для подсчета шагов.
- Notifications / Уведомления - нужно на Android 13+, чтобы работал постоянный фоновый сервис шагомера.

## Что важно для реального подсчета

На Android приложение использует нативный `TYPE_STEP_COUNTER` датчик и foreground service. Это значит, что счетчик продолжает работать в фоне, пока Android не остановит приложение вручную и пока активен сервис шагомера.

Чтобы счетчик работал стабильнее:

- не закрывайте приложение принудительно из настроек Android;
- не отключайте уведомление шагомера;
- после перезагрузки телефона откройте приложение один раз;
- при необходимости отключите жесткую экономию батареи для приложения.

## Где открыть

- Web-preview интерфейса: http://localhost:8082

Web-preview нужен только для просмотра интерфейса в браузере. В браузере нет датчика шагов, поэтому реальные шаги считаются только в Android APK.

## Запуск

```powershell
npm install
npm start
```

Для просмотра интерфейса в браузере:

```powershell
npm run web
```

## Важно

В проекте есть нативная папка `android/`, потому что для полноценного Android-шагомера добавлен собственный модуль и foreground service. Это не Expo Go-приложение для реального использования, а нативный APK.
